# Бинарное дерево поиска (BST) на языке C

Учебный проект с целью научиться работать с одной из базовых структур данных. Реализация на языке C с нуля.

## Что было сделано:

1. Создание узла BST - `BstNode* bst_create_node(int value)`:
   - Выделяет память на куче через `malloc` и возвращает указатель под структуру `BstNode`, являющуюся узлом дерева.
   - Устанавливает числовое значение узла (типа `int`) в поле `root->data`, переданное в функцию.
   - Устанавливает дефолтное значение `NULL` для полей `root->left` и `root->right`, являющихся указателями на дочерние узлы дерева.
   - Возвращает указатель на узел (структуру `BstNode`).

2. Вставка узла в дерево BST - `bool bst_insert_node(BstNode** ptr_root, int value)`:
   - Рекурсивно спускается по дереву, опираясь на инварианты BST, пока не дойдёт до `NULL` в одном из поддеревьев.
   - При обнаружении `NULL` вызывает `bst_create_node`.
   - Через одинарное разыменовывание указателя на указатель на структуру присваивает полю `left/right` родителя адрес узла, который был возвращён `bst_create_node`.

**Объяснение выбранного для функции подхода:**

1. **Избегание лишних переприсваиваний.** Подход через двойные указатели и возвратом функцией значения типа `bool` выбран во избежание лишних переприсваиваний (перезаписей тем же адресом узла) указателей в поля родительской структуры - `left` и `right` (при подходе через одинарные указатели реальный смысл имеет лишь одно присваивание - возврат адреса нового узла, созданного через `bst_create_node`, в поле `left/right` непосредственного родителя, который в данной ситуации является или листом, или имеет лишь одного ребёнка, тогда как остальные переприсваивания подразумевают лишь перезапись значения этих полей родителей тем же самым адресом).

2. **Оповещение о результате вставки.** Возврат `bool` позволяет вызывающему коду понять успешно/неуспешно ли выполнилась вставка в дерево, чего не было бы при подходе со одинарным указателем, когда возвращаемое значение функции, вызванной первично в рамках конкретного рекурсивного стека вызовов, будет в любом случае указателем на узел поддерева (для корневого вызова — корень дерева), что не даёт понять успешна вставка или нет.

3. Поиск узла с минимальным значением в дереве - `BstNode* bst_find_min(BstNode* root)`:
   - Рекурсивно спускается по дереву по левой ветке каждого поддерева до поддерева со значением `NULL` в поле `left` (до отсутствия ребёнка) и возвращает этот узел.

4. Поиск узла с максимальным значением в дереве - `BstNode* bst_find_max(BstNode* root)`:
   - Рекурсивно спускается по дереву по правой ветке каждого поддерева до поддерева со значением `NULL` в поле `right` (до отсутствия ребёнка) и возвращает этот узел.

5. Вычисление глубины дерева - `int bst_tree_height(const BstNode* root)`:
   - Рекурсивно находит высоту левого и правого поддеревьев.
   - Возвращает `1 + max(высота левого, высота правого)` (единица прибавляется, чтобы учесть текущий узел).

6. Удаление узла BST - `bool bst_delete_node(BstNode** ptr_root, int value)`:
   - Рекурсивно спускается по дереву, опираясь на инварианты BST, пока не дойдёт до узла с соответствующим значением (`value == root->data`).
   - В зависимости от комбинации наличия детей у родителя (в том числе в случае их отсутствия) выбирает соответствующий вариант удаления узла:
     - **Отсутствие детей:** освобождение памяти, соответствующей структуре `BstNode` (узлу); присваивание значения `NULL` полю `left/right` родителя через двойной указатель.
     - **Один ребёнок:** сохранение единственного ребёнка в новый указатель; освобождение памяти, соответствующей структуре `BstNode`; присваивание значения указателя на сохранённого ребёнка полю `left/right` родителя через двойной указатель.
     - **Два ребёнка:** вызов функции `BstNode* bst_find_min(BstNode* root)` для правого поддерева удаляемого узла, что позволяет найти донорское значение для удаляемого узла, полностью соответствующее инварианту BST (точно также возможно вызвать `bst_find_max` для левого поддерева); присваивание донорского значения полю `data` удаляемого узла; удаление донорского узла (по варианту 1 или 2) через рекурсивный вызов `bst_delete_node` со значением донорского узла.

7. Поиск узла BST - `BstNode* bst_search_node(BstNode* root, int value)`:
   - Рекурсивно спускается по дереву, опираясь на инварианты BST, пока не дойдёт до узла с соответствующим значением (`value == root->data`) и возвращает указатель на узел с этим значением.

8. Вывод значений узлов дерева в порядке inorder (по возрастанию) - `void bst_inorder_print(const BstNode* root)`:
   - Рекурсивно спускается по дереву в порядке **left-root-right**.
   - Выводит значения узлов левого ребёнка, корня, правого ребёнка в указанном порядке.

9. Вывод значений узлов дерева в порядке preorder - `void bst_preorder_print(const BstNode* root)`:
   - Рекурсивно спускается по дереву в порядке **root-left-right**.
   - Выводит значения узлов корня, левого ребёнка, правого ребёнка в указанном порядке.

10. Вывод значений узлов дерева в порядке postorder - `void bst_postorder_print(const BstNode* root)`:
    - Рекурсивно спускается по дереву в порядке **left-right-root**.
    - Выводит значения узлов левого ребёнка, правого ребёнка и корня в указанном порядке.

11. Освобождение памяти узла BST - `void bst_free(BstNode* root)`:
    - Рекурсивно спускается по дереву в порядке **postorder** (в порядке left-right-root).
    - Освобождает память левого ребёнка, правого ребёнка, корня в указанном порядке.
